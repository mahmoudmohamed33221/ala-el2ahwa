# ع القهوة 🀫☕ — منصة ألعاب

بقت المنصة دلوقتي بتدعم أكتر من لعبة، كل لعبة في ملف/مجلد لوحدها منفصل تمامًا، وفيه صفحة رئيسية واحدة (Hub) بتجمعهم كلهم.

## 📁 هيكل الريبو

```
ala-el2ahwa/
├── www/
│   ├── index.html                 ← الصفحة الرئيسية العامة (Hub) — بتعرض كروت الألعاب
│   ├── manifest.json              ← إعدادات تثبيت التطبيق (PWA) للمنصة كلها
│   ├── service-worker.js          ← كاش أوفلاين للـ Hub + كل لعبة
│   ├── icons/                     ← أيقونة التطبيق العامة (نفس أيقونة "ع القهوة")
│   │   ├── icon-512.png, icon-192.png
│   │   ├── icon-maskable-512.png, icon-maskable-192.png
│   │   ├── apple-touch-icon.png, favicon.ico
│   └── games/
│       └── domino/
│           └── index.html         ← لعبة الدومينو كاملة، ملف مستقل بذاته
│               (لما تضيف لعبة جديدة: games/backgammon/index.html وهكذا)
├── .github/workflows/android-build.yml
├── package.json
├── capacitor.config.json
├── icon-source.png
├── LICENSE
└── .gitignore
```

## 🎮 إزاي النظام شغال

- **`www/index.html`** هي أول صفحة بتفتح (سواء على الويب أو جوه تطبيق الأندرويد). فيها كروت لكل لعبة، كل كارت بيروح لملف `index.html` بتاع اللعبة دي جوه `games/<اسم-اللعبة>/`.
- **كل لعبة معزولة تمامًا**: كل الكود والتنسيقات والصور بتاعت الدومينو موجودة بس جوه `games/domino/index.html`. تقدر تفتحه وتعدل فيه (تضيف مستوى صعوبة، تغيّر شكل، تصلح باج) من غير ما تأثر على أي لعبة تانية أو على صفحة الـ Hub.
- في أعلى شاشة القائمة الرئيسية بتاعة الدومينو نفسها، ضفتلك لينك صغير "↩ كل الألعاب" يرجعك لصفحة اختيار الألعاب تاني.

## ➕ إزاي تضيف لعبة جديدة بعدين

1. اعمل مجلد جديد: `www/games/<اسم-اللعبة>/`
2. حط فيه ملف `index.html` مستقل خاص باللعبة دي (بنفس فكرة ملف الدومينو — ملف واحد شامل كل حاجة، أو تقسمه لملفات CSS/JS منفصلة لو كبر).
3. ارجع لـ `www/index.html` وضيف كارت جديد جوه `.games-grid` بنفس شكل كارت الدومينو، وغيّر بس `href` ليشاور على مجلد اللعبة الجديدة.
4. (اختياري) ضيف مسار اللعبة الجديدة في قايمة `ASSETS` بملف `www/service-worker.js` عشان تشتغل أوفلاين هي كمان.

بالطريقة دي حجم كل ملف لعبة بيفضل صغير ومنفصل، وميكبرش ملف واحد فيه كل الألعاب مع بعض.

## 🛠️ خطوات النشر على GitHub (Upload)

1. من **Add file → Upload files** ارفع محتويات هذا المشروع بالكامل فوق الموجود عندك، بحيث يبقى عندك `www/index.html` (الـ Hub) و`www/games/domino/index.html` (اللعبة) بدل الوضع القديم اللي كان فيه `www/index.html` هو الدومينو نفسه.
2. لو عندك نسخة قديمة، احذف `www/index.html` القديم الأول قبل الرفع عشان مايحصلش تعارض.

## ⚙️ الـ GitHub Action (بناء APK)

نفس الفكرة زي قبل كده — أي push على `main` بيبني APK تجريبي (Debug) تلقائيًا وبتلاقيه في تبويب **Actions → آخر run → Artifacts**. لأن `capacitor.config.json` بيشاور على `webDir: "www"`، هيتغلف كل حاجة جوه `www/` (يعني الـ Hub وكل الألعاب) في تطبيق أندرويد واحد، وأول شاشة تفتح فيه هتكون صفحة اختيار الألعاب.

## 📝 ملاحظات
- الأيقونة العامة للتطبيق (اللي في `www/icons/`) هي نفسها أيقونة "ع القهوة" الأساسية، مش خاصة بلعبة الدومينو بس.
- الـ APK لسه Debug (تجريبي غير موقّع) — لو عايز نسخة Release للنشر على المتجر قولي وهنضيف التوقيع.
